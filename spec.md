## Core Goal
A master addon that:
1. On Character A → /telneui → Snapshot: reads all settings into a named profile
2. Logout → Login as Character B
3. On Character B → /telneui → Import: applies full profile, then /reload finishes it

This covers:
- Which addons are enabled/disabled
- All addon SavedVariables (copied from memory while in-game)
- Macros (general + character-specific)
- Keybinds
- Chat window layout and filters
- UI frame positions
- EditMode layout

## Critical WoW Limitations (always respect these)
- Addons CANNOT toggle other addons on/off mid-session — at login only
- Addons CANNOT write directly to disk — only to their own SavedVariables
- SavedVariables are written to disk on logout and read at login
- Other addons' SavedVariables ARE accessible in memory during the session
- Addon enable/disable state changes require /reload or relog to take effect
- Always design around these — never try to work around the sandbox

## Realistic Session Flow
Character A (e.g. ninenines-silvermoon):
  /telneui → Profiles tab → [Snapshot All] → name the profile → confirm
  → telneUI reads everything into telneUISavedVars (account-wide)

Logout → Login as Character B (e.g. telne-silvermoon):
  /telneui → Profiles tab → select profile → [Import All] → confirm dialog
  → telneUI writes macros, keybinds, chat, frames, editmode, addon settings
  → Shows: "Reload required to apply addon states"
  → [Reload Now] button triggers ReloadUI()

# telneUI — Claude Code Project Instructions

## What this project is
A World of Warcraft addon called telneUI. It is a personal UI profile
manager that snapshots and restores a character's full UI setup
(macros, keybinds, chat, frames, editmode, addon states and configs)
so it can be cloned to any other character.

## Critical WoW addon rules (never violate)
- Only files listed in telneUI.toc are loaded by WoW
- Never add .claude/, README.md, or any non-Lua file to the .toc
- SavedVariables tables are written to disk on logout only
- Addons cannot toggle other addons mid-session — only at login/reload
- Always use account-wide SavedVariables (telneUISavedVars) so profiles
  work across characters
- Target retail WoW, latest patch (check Interface version if unsure)

## Load order (respects .toc declaration order)
1. Core.lua — addon init, SavedVariables, slash command
2. ProfileManager.lua — profile CRUD
3. Snapshot.lua — reads current character state
4. Importer.lua — writes profile to current character
5. UI/Widgets.lua — must load before all other UI files
6. UI/MainFrame.lua — master panel and tab system
7. UI/ProfilesTab.lua, AddonsTab.lua, SettingsTab.lua — tab content
8. Modules/*.lua — each module is self-contained

## Architecture rules
- All persistent data lives in telneUISavedVars (never in globals)
- Modules are stateless — they only read/write via Snapshot and Importer
- UI files only call ProfileManager — never read SavedVars directly
- Deep copy all foreign addon tables — never hold references
