## [1.0.0] — In Development

### Milestone 1 — UI Shell (current)
- Initial repo structure and WoW addon scaffold
- Dark ElvUI-style main panel (700×500, draggable, position-remembered)
- Three-tab layout: Profiles, Addons, Settings
- Reusable widget library (CreateButton, CreateLabel, CreateScrollFrame, etc.)
- `/telneui` and `/tui` slash commands
- Stub files for all modules (Macros, Keybinds, Chat, Frames, EditMode, AddonSettings)
